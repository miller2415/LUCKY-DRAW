# 🎡 Lucky Draw

這是一個基於 HTML5 Canvas 開發的高級網頁轉盤抽獎系統。本版本整合了靈活的獎項管理、即時庫存扣除、CSV 資料處理，以及優化後的右側指針定位與得獎備註功能。

## ✨ 核心功能

- **專業視覺設計**：採用 Glassmorphism（毛玻璃）風格，支援響應式佈局（手機/電腦皆可流暢使用）。
- **精準權重演算法**：支援自定義獎項權重，確保抽獎機率符合設定。
- **動態庫存管理**：可開啟庫存模式，當獎項數量歸零時自動從轉盤中移除。
- **增強型紀錄系統**：
  - 自動記錄獲獎時間與獎項。
  - **[新功能]** 支援中獎人姓名或備註的即時編輯。
  - **[新功能]** 支援單筆紀錄刪除功能。
- **高度自定義**：支援上傳獎項圖片、自定義顏色、轉動時間設定。
- **資料持久化**：所有設定與紀錄皆自動儲存於瀏覽器的 `LocalStorage`，重新整理也不會消失。
- **資料匯入/匯出**：完整支援 CSV 格式匯入獎項清單，並可匯出得獎紀錄進行後續報表作業。

## 🚀 快速上手

1. **執行檔案**：直接使用瀏覽器開啟 `index.html`（或合併後的檔案）。
2. **編輯獎項**：在右側「獎項編輯」標籤頁中新增或修改內容。
3. **開始抽獎**：點擊轉盤中央的 **GO** 或指針進行抽獎。
4. **管理紀錄**：抽獎結束後會跳出視窗要求輸入備註，隨後可在「紀錄」分頁查看。

## 🛠 技術棧 (Tech Stack)

- **Frontend**: Vanilla JavaScript (ES6+), HTML5 Canvas, CSS3 (Flexbox & Grid).
- **Libraries**: 
  - [PapaParse](https://www.papaparse.com/): 處理 CSV 解析。
  - [Canvas-Confetti](https://www.npmjs.com/package/canvas-confetti): 噴灑紙屑特效。
  - [FontAwesome](https://fontawesome.com/): UI 圖示。

## ⚙️ 開發者備註

### 指針邏輯說明
本版本將指針固定於 **右側 (0度位)**。在計算中獎角度時，使用了以下偏移邏輯：
- 轉盤弧度計算：`arc = (2 * Math.PI) / totalPrizes`
- 旋轉目標：將中獎索引 `idx` 映射至 0 度位置，並加上隨機圈數以達到視覺隨機感。

### 資料儲存
資料儲存鍵值為：
- `wheel_v5_merged_prizes`: 存儲獎項配置。

- `wheel_v5_merged_hist`: 存儲得獎歷程。
